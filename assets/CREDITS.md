# World board reference

The map loads the unmodified 2952×2952 board texture distributed with the publisher-authorized **War Room** Tabletop Simulator reference (Workshop item 2419016456). Game and board artwork: Nightingale Games / the original creators. The original image is loaded from its reference CDN and cached by the browser for offline use. Digital reference credited on its workshop page to jotakami, tomgale and shershot.

Source page: https://steamcommunity.com/sharedfiles/filedetails/?id=2419016456
Source image: https://cdn.steamusercontent.com/ugc/1666856894575883627/D5EA1F53AE0778824FB9AD2FE5466EF2253047CE/

The browser overlay registers the printed board at local extents ±8.3, reversing the TTS horizontal axis to match the image. Original game-state badges and interactive hit areas are rendered separately. No claim of ownership of the board artwork or publisher endorsement is made.
